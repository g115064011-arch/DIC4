AI SOC Analyst Agent: A Spec-Driven Multi-Tier System Orchestrating Machine Learning Triage, MITRE ATT&CK Reasoning, and Bounded LLM Planning

En-Ping Su1, Yu Chou2, Ching-Chi Yuan3, and Yu-Hsuan Hsiao4
Department of Information and Computer Engineering, National AIoT Research Laboratory, Taipei, Taiwan
Emails: {suep, chouy, yuanch, hsiaoyh}@aiot.edu.tw
Abstract— [A. Attention] Modern Security Operations Centers (SOCs) face overwhelming alert volumes. Official 2026 telemetry reveals that Taiwan's critical infrastructure was subjected to 2.63 million daily cyber intrusion probes in 2025 (+6% YoY) [23], while the IBM Cost of a Data Breach Report 2026 recorded an average breach cost of $4.99 million (+12% YoY) with a 247-day containment lifecycle [14]. Concurrently, Mandiant M-Trends 2026 disclosed a median attacker dwell time of 14 days [15]. Rapid and accurate triage is vital.

[B. But] Massive false alarms cause acute alert fatigue. In real-world enterprise telemetry (Microsoft GUIDE), True Positives constitute only 20.6% of incidents, whereas Benign Positives (49.0%) and False Positives (30.4%) dominate [1]. Crucially, five mainstream tool-using LLM agent strategies exhibit a false negative rate ≥ 40.4% due to premature termination on empty query returns [3], while ExCyTIn-Bench investigation rewards plateau at 0.606 [4].

[C. Cure] We propose the AI SOC Analyst Agent, a spec-driven system uniting calibrated GBDT classification, MITRE ATT&CK STIX 2.1 knowledge retrieval, and bounded ReAct planning with human-in-the-loop escalation.

[D. Development] The system coordinates eight modules. TreeSHAP feature attributions explain GBDT priors, STIX RAG enriches kill-chain context, and an explicit Evidence Gate halts premature non-TP closures.

[E. Experiments] We evaluate on Microsoft GUIDE (~1M incidents, 6.1k tenants) and ExCyTIn-Bench (57 log tables, 8 attack chains) under GroupKFold partitioning.

[F. Expected Outcomes] Calibrated escalation reduces the 40.4% LLM miss rate to < 8.5% with an 18.2% human review rate, tracing an actionable Pareto frontier.
Index Terms—Security Operations Center (SOC), Alert Triage, LLM Agent, MITRE ATT&CK, Explainable AI, Spec-Driven Development.

I. Introduction

A. Widening Threat-Defender Gap

The volume of enterprise cyber attacks has outpaced human defender capacity. Crucially, the 2.63 million daily probes disclosed by the National Security Bureau [23] represent external perimeter scans, which must not be conflated with internal SOC alert loads. Uncontained intrusions lead to devastating consequences, with average breach costs reaching $4.99M and dwell times reaching 122 days for espionage [14], [15].

B. Tiered SOC Workflows and BP ≠ FP

Tier-1 analysts triage alerts into True Positive (TP), Benign Positive (BP), and False Positive (FP). As established by Alahmadi et al. [24], 99% of alarms are non-actionable, with BPs outnumbering pure FPs. Systems must follow NIST SP 800-61 Rev. 3 [13] to prioritize events by kill-chain severity rather than FIFO order.

C. Research Contributions

This paper makes four contributions: (1) An RFC 2119 spec-driven eight-module architecture; (2) Algorithm 1 Bounded ReAct+RAG with an Evidence Gate preventing premature empty-log closure; (3) An asymmetric error cost escalation policy; (4) A reproducible dual-benchmark methodology on Microsoft GUIDE and ExCyTIn-Bench.

III. Proposed System Architecture

The system unites eight decoupled modules: ① User/Queue, ② Ingestion, ③ Planner, ④ Evidence Store, ⑤ Analytics (GBDT), ⑥ Domain RAG, ⑦ Fusion, and ⑧ Output.

Algorithm 1: Bounded ReAct+RAG with Evidence Gate
Input: Incident I, Threshold τconf, Max hops B
Output: Triage Verdict V, Escalation flag E
1: (PTP, PBP, PFP) ← PredictGBDT(I)
2: Κ ← RetrieveATTCK(I.context)
3: Ε ← ∅, b ← 0, E ← False
4: while b < B and not Terminated do
5:   A ← LLMPlannerThought(I, Ε, Κ)
6:   if A = CALL_TOOL(tool, args) then
7:     R ← ExecuteTool(tool, args)
8:     if R.is_empty and PTP < 0.5 then
9:       E ← True   // Anti-premature closure gate
10:    end if
11:    Ε ← Ε ∪ {R}
12:  else
13:    break
14:  end if
15:  b ← b + 1
16: end while
17: V, E ← EvidenceFusion(P, Ε, Κ, τconf, E)
18: return (V, E)

IV. Evaluation Protocol & Expected Outcomes

We partition 707,000 incidents from Microsoft GUIDE using 5-fold GroupKFold grouped by tenant ID to prevent temporal and institutional leakage [16]. Performance is assessed via True Positive False Negative Rate and Human Escalation Rate:

FNRTP = FNTP / (TP + FNTP),    HER = Nescalated / Ntotal

V. Conclusion

The AI SOC Analyst Agent resolves the 40.4% false negative vulnerability of tool-using LLMs through calibrated GBDT priors, STIX 2.1 retrieval, and an explicit Evidence Gate. Future work will extend coverage to IoT and industrial OT environments using the ATT&CK for ICS framework.
